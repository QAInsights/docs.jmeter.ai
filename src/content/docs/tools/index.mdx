  ## Architecture & Client-Side Privacy

  Every tool in this catalog executes **100% locally in your web browser**. No test plan files (`.jmx`), cURL commands, API tokens, response bodies, or infrastructure IP addresses are uploaded, logged, or sent to any remote server or third-party telemetry service.

  * **Converters & Linters:** DOM parsers and Web Workers process your files entirely in browser memory.
  * **Sizing Calculators:** Mathematical algorithms based on Little's Law, Erlang queues, and JVM footprint formulas run instantly with zero latency.
  * **Correlation Sandbox:** Practice endpoints can be targeted against the hosted cloud edge (`https://docs.jmeter.ai/api/sandbox`) for single-thread debugging or run completely offline against your own local Node.js server (`http://localhost:8787`).
