*Part of the **Logic Controllers** category. Also documented in context in the [full Component Reference](/user-manual/component-reference/#recording-controller).*

![Recording Controller](/images/screenshots/logic-controller/recording-controller.png)

The Recording Controller is a place holder indicating where the proxy server should
record samples to.  During test run, it has no effect, similar to the Simple Controller.  But during
recording using the [HTTP(S) Test Script Recorder](/components/http-s-test-script-recorder/), all recorded samples will by default
be saved under the Recording Controller.
