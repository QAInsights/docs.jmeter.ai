*Part of the **Listeners** category. Also documented in context in the [full Component Reference](/user-manual/component-reference/#view-results-in-table).*

![View Results in Table](/images/screenshots/table_results.png)

This visualizer creates a row for every sample result.
Like the [View Results Tree](/components/view-results-tree/), this visualizer uses a lot of memory.

By default, it only displays the main (parent) samples; it does not display the sub-samples (child samples).
JMeter has a "`Child Samples`" check-box.
If this is selected, then the sub-samples are displayed instead of the main samples.
